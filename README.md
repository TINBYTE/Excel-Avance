## 📖 About
This repository is designed to provide a structured learning path for advanced Excel users. You will find courses, hands-on exercises, and sample datasets to practice your Excel skills, including formulas, VBA, Power Query, and data visualization.

## 🛠 Installation Guide
To use the materials in this repository, follow these steps:
1. Ensure you have Microsoft Excel installed.
2. Clone this repository using:
   ```sh
   git clone https://github.com/your-username/Excel-Avance.git
   ```
3. Open Excel and start practicing!

## 🚀 How to Use
1. Navigate to the **Course Materials** folder to start learning.
2. Try solving exercises in the **Exercises** folder.
3. Check solutions and compare with your approach.
